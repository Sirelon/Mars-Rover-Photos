## 4. Reliability

- **New fatal on 5.3.0** — `NoSuchMethodError: WindowMetrics.getDensity()` in
  `MarsNavigationSuite` (`shared/.../presentation/navigation/MarsBottomBar.kt`), 1 install.
  `getDensity()` is an API 34 method; the adaptive navigation-suite library calls it on a device
  that lacks it.
- **New ANR on 5.3.0** — `AndroidImageOperations.saveImage` blocks on a binder call, 1 install.
- **Gone since prev** (all 5.2.0): `ImagesPagerContent` IndexOutOfBounds (8 events, 3 installs),
  WorkManager `JobScheduler.forNamespace` (6 events), two OutOfMemory issues, UMP consent-form
  dismiss crash.
- **Feed errors**: Android 85 `feed_error` events from ~15 users; the top reason is
  `UnknownHostException` (device offline), mostly on 5.2.0.
- **Ads**: Android `ad_load_failed` ÷ `ad_loaded` = 37 % (202/545), prev 35 %. iOS < 1 %.

## 6. Insights

1. **The install spike is low-quality traffic.** 103 new users from Ethiopia, India, Pakistan
   and Indonesia; 86 of them (83 %) uninstalled in the window, vs 40 % (56/139) for all other
   countries. Ethiopia: 49 installs on 28 different device models, spread over a month, all on
   5.2.0 — real devices, not a Play pre-launch farm. _Hypothesis_: a third-party store, an
   "install for reward" network or a Play "similar apps" placement. → Check Play Console
   Acquisition reports by country and referrer for October.
2. **Android new installs still land on 5.2.0.** All installs from the four countries above run
   5.2.0, a month after 5.3.0. _Hypothesis_: 5.3.0 is on a staged rollout or excludes some
   devices. → Check the Play Console release rollout %; finish it if it is staged.
3. **Real users are healthier than the headline.** Without the four-country cohort, uninstall
   rate is ~40 % and returning users 37 % (51/139). iOS week-1 retention (26 %) is double
   Android (12.8 %). → Judge product changes on the "other countries" cohort and iOS.
4. **Stability improved a lot with 5.3.0.** Crashed installs 7 → 1; the pager and OOM crashes are
   gone. One new fatal remains. → Guard the navigation-suite path (or bump the adaptive library)
   for the `WindowMetrics.getDensity` crash.
5. **`images-assets.nasa.gov` fails a third of the time on both platforms.** That is the
   Spirit / Opportunity image host. _Hypothesis_: missing thumbnail sizes (404) behind
   `images-api.nasa.gov` search results. → Probe a sample of failing URLs with curl and fall
   back to a different rendition.
6. **Support purchases fell**: iOS `support_purchase` 2 (prev 8), Android 0 (prev 1). The
   coffee-tip change (#222) shipped just before this window. RevenueCat not checked. → Compare
   in RevenueCat once the window holds more data.
